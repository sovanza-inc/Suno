# TASKS — work queue for the Claude self-improvement loop

The Claude loop reads this file each iteration, picks the first unchecked task,
executes it, and marks it done. New tasks can be added here by humans or by
the loop itself (when it identifies follow-up work).

This is **separate** from `NEXT_TASK.md`, which is auto-generated by the
**Python orchestrator** based on training trends. Both files are inputs to the
loop — TASKS.md is the explicit queue, NEXT_TASK.md is the planner's
recommendation.

---

## Format

```
- [ ] **Task slug** — one-line description.
  Acceptance: how we know it's done.
  Constraint: anything special (file scope, locked decisions to respect).
```

When done, mark `[x]` and move under `## Done`. Always run `make test` and
`make lint` before committing.
